5-Axis Python 2024

Custom 5-Axis Slicing Engine

Project Overview

Developed a custom slicing engine using Python and Perl to enable non-linear, 5-axis toolpaths for additive manufacturing — moving beyond the constraints of conventional 3-axis FDM printing.

Key Contributions

  • Developed custom slicing logic for non-linear 5-axis toolpaths, expanding beyond traditional planar layer approaches.
  • Created a sub-slicing method that dynamically adjusts print parameters locally for complex geometry sections.
  • Implemented advanced G-Code generation minimizing support structure requirements, improving material efficiency.
  • Improved mechanical isotropy of printed parts by aligning layer deposition direction with load paths.

Technologies Used

Python, Perl, G-Code, CAM principles, FDM/Additive Manufacturing, mesh processing, toolpath optimization.
